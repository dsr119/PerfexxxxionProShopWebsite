# Perfexxxion Pro Shop website

Static site for www.perfexxxxionproshop.com, hosted on GitHub Pages. Plain HTML and CSS, no build step.

- Each page is a folder with an `index.html`, so the old Google Sites URLs (`/bowling-balls`, `/schedule-an-appointment/lesson`, ...) keep working.
- Styles live in `assets/style.css`; colors are the variables at the top.
- Photos go in `images/` (see `images/README.md` for the expected file names).
- `CNAME` holds the custom domain for GitHub Pages.

## Editing

Edit the HTML file for a page directly on GitHub (pencil icon) and commit. Pages redeploys automatically.
