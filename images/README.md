# Images

The pictures here are drawn placeholders (SVG) until real photos are available.
To swap one in, add the photo here and change the matching `.svg` name in the page's `index.html`.

| --- | --- |
| `logo.svg` | Header logo on every page, home page, browser tab icon |
| `schedule-1.svg` | Schedule an Appointment, top |
| `schedule-2.svg` | Schedule an Appointment, bottom |
| `drilling.svg` | Drilling/Fitting, top |
| `lesson.svg` | Lesson, below the text |
